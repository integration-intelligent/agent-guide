# 周末活动计划

适用：用户想根据活动笔记和出行偏好，安排一次轻松的周末出门活动。

1. 规划真实行程时，从请求与显式偏好中确认城市、日期或时间范围、可用时长、预算与交通方式；缺少影响安排的信息时先询问，相对日期不明确时请用户给出具体日期。若明确使用教学虚构地点，只做示意规划，不必索取真实出行城市和日期。
2. 用 search_notes 搜索活动主题，再用 read_note 读取相关笔记。教学虚构地点只能作为练习候选，不能当成真实出行推荐。
3. 给一个主方案和一个雨天备选，交通、活动、休息与机动时间的合计不超过用户可用时长。没有实时路线工具时，交通时长只能标为预留估计。
4. 根据用户明确保存的偏好控制步行强度与交通方式；费用缺少来源时写“待核实”，不假称预算已经满足。
5. 若启用了联网，按需核对公开来源，标出来源URL、资料日期及仍待核实的问题。历史活动、场馆名单、搜索摘要均不能证明本周仍开放、有票或无需预约。
6. 没有联网工具时，不虚构天气、地铁时刻、票价、实时营业状态或预约结果；列出出门前要核对的事项。
7. 输出行程草稿、时间分配、雨天备选和笔记文件名。除非用户明确要求保存，否则不调用 add_task；保存待办不等于购票或预约。
